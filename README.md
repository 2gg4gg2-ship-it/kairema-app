## 💡 Что такое Kairema

Kairema — Android-приложение, которое превращает телефон в рабочее место для общения с искусственным интеллектом.
Это **BYOK-клиент** (Bring Your Own Key): приложение не продаёт доступ к моделям и не стоит между вами и провайдером.
Вы подключаете **свой** сервис (OpenAI, Anthropic, OpenRouter, Gemini, DeepSeek, Groq и многие другие), вставляете **свой** API-ключ, и
запросы идут напрямую от телефона к провайдеру.

**Зачем это нужно**

| Задача | Как помогает Kairema |
|---|---|
| Хочу пользоваться разными моделями в одном месте | Любое число провайдеров и моделей, переключение одним нажатием, бесплатные модели в списке сверху |
| Не хочу зависеть от одной подписки | Платите только за то, что тратите, счётчик токенов и цены под каждым ответом, месячный лимит |
| Работаю с кодом с телефона | Настоящий терминал, кнопка «Выполнить» под командами, агент-программист с инструментами как у Codex и Claude Code |
| Нужен ИИ, который помнит меня | Память: профиль и факты с категориями, подбор под вопрос, извлечение моделью |
| Много чатов, всё теряется | Поиск по чатам и коду, теги, закладки, черновики, резервная копия, облачная синхронизация |
| Важна приватность | Ключи в Android Keystore, чаты на устройстве, облако по желанию, нет рекламы и аналитики |

**Принципы проекта**

- **Автономность.** Всё, что можно, работает без облака: чаты в SQLite на телефоне, шрифты встроены, поиск по чатам локальный.
- **Честность.** Приложение не выдумывает, какая модель отвечает (оно передаёт ей точный id), а в документации отмечено, что проверено и что нет.
- **Модульность.** Каждая функция лежит в своей папке и отключается удалением папки (см. [Для разработчиков](#-для-разработчиков)).
- **Минимум зависимостей.** Из внешних библиотек подключён только OkHttp.

## 📲 Скачать и установить

1. Откройте раздел **[Releases](../../releases/latest)** этого репозитория и скачайте `Kairema-<версия>.apk`.
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника (браузера или файлового менеджера), разрешите.
3. Нужен **Android 8.0 (API 26) или новее**.

**Обновления.** Новые версии ставятся поверх старых без потери данных: подпись приложения постоянная.
Внутри приложения есть **Настройки → Обновление**: оно проверяет последний релиз на GitHub, показывает, что нового, скачивает APK
и открывает установку. Раз в сутки приложение проверяет релиз само (это можно выключить).
Адрес загрузки проверяется строго: только `https://github.com/<репозиторий>/releases/download/…`, иначе установка не начинается.

> Если на телефоне уже стоит сборка, подписанная другим ключом (например, ранние debug-сборки), Android не даст обновить поверх.
> Тогда нужно один раз удалить старую версию и поставить новую. Перед этим сделайте **резервную копию** (Настройки → Резервная копия).

## 🚀 Быстрый старт за 3 минуты

1. **Откройте приложение.** Первый запуск показывает короткое приветствие «Твои идеи. Твой ИИ.» (один раз) и фирменную заставку.
2. **Подключите провайдера.** Настройки → Провайдеры → «Добавить». Выберите сервис из списка (адрес API подставится сам) или введите свой адрес.
3. **Вставьте API-ключ.** Приложение сразу проверяет ключ и показывает результат. Ключ уходит в защищённое хранилище Android и больше в интерфейс не возвращается.
4. **Выберите модель.** Приложение загрузит список моделей провайдера: бесплатные сверху, у каждой видны метки возможностей (картинки, Think, зрение).
5. **Пишите.** Ответ приходит потоком, с форматированием, таблицами и кодом.

Нет ключа? Бесплатные модели есть у OpenRouter, Groq, Cerebras, SambaNova, Google Gemini и других сервисов из списка.
В приложении есть **Справка** (Настройки → Справка): 14 разделов простым языком, от быстрого старта до словаря терминов.

## ✨ Возможности

### 💬 Чат

- **Потоковый ответ**: текст появляется по мере генерации. Кнопка **«Стоп»** (стрелка отправки превращается в квадрат) останавливает ответ, напечатанное остаётся, под ним «Остановлено. Продолжить».
- **Markdown без компромиссов**: заголовки, списки, цитаты, **жирный**, *курсив*, ~~зачёркнутое~~, ==выделение==, таблицы (широкая таблица листается вбок), блоки кода с подсветкой и кнопкой копирования. Разметка строится безопасно через DOM, без `innerHTML`, ссылки только `http(s)`.
- **Другой ответ**: под последним ответом кнопка ↻ создаёт новый вариант, переключатель ‹ 1/2 › позволяет вернуться к прежнему.
- **Размышления модели**: у моделей с Think они свёрнуты в строку «Думает…» со счётчиком символов, поэтому не загромождают чат.
- **Режимы Think / Instant**: Anthropic получает параметр thinking, OpenRouter reasoning, остальным режим передаётся инструкцией. Время ожидания ответа до 30 минут, так что модель успевает подумать.
- **Язык ответа**: ИИ отвечает на языке вопроса. Интерфейс на русском и английском.
- **Понимание запроса**: общая инструкция всем моделям (выполнить все условия, «улучши» значит работать с файлом из чата, не выдумывать данные).
- **Качество на слабых моделях**: короткие жёсткие правила языка и таблиц, упрощённый режим для маленьких моделей, фильтр иероглифов в ответах на русском.
- **Быстрые длинные чаты**: сразу рисуются последние 60 сообщений, ранние подгружаются кнопкой «Показать ранние» (замер: 500 сообщений, 501 мс → 49 мс при замедлении процессора в 6 раз).
- **Плавный скролл**: чат не тянет вниз, пока вы листаете выше или читаете. Есть маленькие кнопки «вверх» и «вниз».
- **Выделение текста** только там, где нужно: в ответах ИИ, выводе терминала и полях ввода.
- **Черновик не пропадает**: недописанное сообщение сохраняется для каждого чата и возвращается, даже если уйти в настройки или закрыть приложение.
- **Уведомление «Ответ готов»**, если вы свернули приложение. Служба переднего плана не даёт Android убить долгий запрос.

### 🔌 Провайдеры и модели

- **Любые OpenAI-совместимые API и Anthropic (Claude)**. Количество провайдеров не ограничено, в чате провайдера и модель можно менять в строке вверху.
- **Готовые сервисы** (адрес подставляется сам): OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Kimi (Moonshot), Groq, SambaNova, Cerebras, Together AI, Mistral, Mistral Codestral, xAI (Grok), CometAPI, ZenMux, TeamoRouter, BazaarLink, Token Harbor, NaraRouter, Haimaker, Keiro, Gurouter. Подойдёт и любой свой адрес.
- **Проверка ключа сразу при добавлении**, затем список моделей, затем проверка выбранной модели.
- **Бесплатные модели сверху**, платные ниже (если провайдер сообщает цены), вкладки и счётчик в статусе.
- **Авто-определение возможностей** модели (картинки, Think, зрение) по данным провайдера и по имени. Лишние пункты меню скрываются, метки видны в списке.
- **Модель честно называет себя**: ей передаются точный id модели, имя провайдера и включённые режимы, выдумывать другую модель запрещено.
- **Ключи в Android Keystore**. В интерфейс ключ не передаётся вообще.
- **Понятные ошибки**: «слишком большой запрос» подсказывает `/compact`, 401/403 говорят про ключ, 404 про адрес, 429 про лимит.

### 📎 Вложения и файлы

- **Фото** из галереи и с камеры. HEIC и большие снимки ужимаются до 1568 px с поворотом по EXIF.
- **Текстовые файлы и код** вставляются в запрос.
- **PDF для любой модели**: текст достаётся прямо в приложении (без библиотек), у сканов страницы уходят картинками, если модель умеет зрение. Anthropic получает файл целиком.
- **Поиск по большим файлам (локальный RAG)**: файл больше 30 000 знаков не вставляется целиком, а режется на куски (около 1200 знаков), и к вопросу прикрепляются только подходящие (BM25 со стеммингом). Индекс хранится на телефоне.
- **Вложения в чате**: плитки под сообщением, фото на весь экран (увеличение, сохранить, поделиться), просмотр текста файла.
- **Входящее «Поделиться»**: текст, ссылку или файл из другого приложения можно отправить в Kairema, откроется новый чат. В меню выделенного текста Android есть пункт «Kairema».

### 🗂 Файлы из ответов ИИ

Модель сама файлы не создаёт, поэтому приложение делает их из ответа:
- блок `html` получает **«Предпросмотр», «PDF», «Скачать», «Поделиться»**;
- блоки `csv`, `markdown`, `svg` скачиваются и отправляются;
- у таблицы есть выгрузка в CSV;
- чат целиком можно переслать как страницу для чтения (.html), PDF или .md: ваши вопросы справа в пузырях, ответы слева.

### 🌐 Поиск в интернете и глубокое исследование

- **Кнопка-глобус** в поле ввода: зелёная, когда поиск работает, красная, когда выключен.
- **Модель сама решает**, нужен ли поиск, и составляет запросы с учётом всей беседы, а не сырого текста вопроса.
- **Поисковые провайдеры**: Tavily, Brave Search, Serper, Exa, You.com, Firecrawl, Keiro. Результаты очищаются и отбираются по релевантности.
- **Встроенный поиск моделей**: OpenRouter и Claude используют собственный поиск провайдера (плитка «Поиск модели»).
- **Глубокое исследование**: модель составляет 4–6 запросов, приложение ищет по каждому, и модель пишет отчёт со ссылками на источники.

### 🖼 Создание изображений

Через OpenRouter (модель с выводом картинок, по умолчанию `google/gemini-2.5-flash-image`) и OpenAI-совместимые API (`/images/generations`).
Картинку можно сохранить в «Загрузки» или отправить в другое приложение. Anthropic изображения не создаёт, приложение подскажет подключить другого провайдера.

### 🧠 Память

ИИ помнит вас между чатами, и вы всегда видите, что именно:
- **Профиль** («что важно знать обо мне») подставляется в каждый запрос.
- **Факты** по категориям: личное, работа, предпочтения, интересы, люди, цели, техника, прочее. Факты можно закреплять, править, удалять («Удалить все факты» с подтверждением).
- **Умное извлечение**: после ответа модель в фоне находит новые факты (можно выключить).
- **Подбор под вопрос**: в запрос попадают только подходящие факты (до ~1800 знаков), остальное не тратит токены. Если фактов не больше 20, модель видит все.
- Память подмешивается как тихий контекст: модель не пересказывает то, о чём не спрашивали.

### 🎭 Роли, шаблоны и команды «/»

В поле ввода наберите **«/»** и появится список команд. Кнопка **«Шаблоны»** рядом с отправкой открывает то же самое с поиском.

| Тип | Что делает | Примеры |
|---|---|---|
| **Роль** | Системная инструкция на весь чат, над полем ввода плашка с названием | `/translate` переводчик, `/short` коротко, `/teacher` учитель, `/code` программист, `/termux` помощник по Termux |
| **Шаблон** | Готовый текст вставляется в поле ввода | `/fix` исправить код, `/explain` объяснить, `/summary` резюме, `/edit` улучшить текст |
| **Действие** | Выполняется сразу | `/compact` сжать контекст, `/new` новый чат, `/agent` агент вкл/выкл, `/agent-set`, `/marks` закладки, `/backup` резервная копия |

Свои роли и шаблоны: Настройки → «Роли и команды». Ваши «Шаблоны промтов» тоже доступны как `/название`.

### 📏 Контекст

- **Шкала контекста** над полем ввода показывает, сколько «окна» модели занято. После 80% краснеет, по нажатию предлагает сжать историю или начать новый чат.
- **`/compact`**: старая часть чата заменяется кратким пересказом для модели, сообщения на экране остаются.
- **Автосжатие**: приложение само сжимает историю, когда она подходит к пределу.

### 💻 Терминал

Вкладка **«Терминал»** даёт настоящую оболочку, две на выбор:
- **Песочница приложения** (`/system/bin/sh`): работает сразу, без установки, есть помощники `ll`, `la`, `tree`, `calc`, `help`.
- **Termux** (если установлен): полноценное окружение с `git`, `python`, `node`, `pip` и пакетами. Нужно разрешение `RUN_COMMAND` и включённая опция `allow-external-apps`.

Как это связано с ИИ:
- Под блоками ```` ```bash ```` в ответах появляется кнопка **«Выполнить»**: команда запускается только после вашего подтверждения.
- Результат можно отправить ИИ одной кнопкой. Если команда упала, есть **«Отправить ошибку ИИ на разбор»**.
- Потенциально опасные команды (`rm -r`, `dd`, `mkfs`, `chmod -R`, обращения к `/data/data`, `/sdcard` и подобное) распознаются и требуют отдельного подтверждения.
- Когда команда пишет в файлы, приложение показывает **дифф** (что изменилось) и позволяет **откатить** правки.
- Вывод можно выделять пальцем, есть кнопки «Всё», «Последний вывод», «Выделить», «Отправить»; история команд сохраняется.
- Слабые модели не всегда оформляют команды правильно, поэтому приложение допускает несколько форматов записи команд.

### 🗃 Порядок в данных

- **История чатов** в SQLite на телефоне: создание, переименование, закрепление, удаление, «Удалить все чаты». При создании чата можно сразу дать название или пропустить (название подставится по первым строкам).
- **Умный поиск** по чатам, сообщениям и коду (индекс SQLite FTS5, подсветка, фильтры); если FTS5 недоступен, работает запасной режим.
- **Теги чатов**: в меню чата (⋯) пункт «Теги», сверху списка ряд меток для фильтра.
- **Закладки**: звёздочка под ответом, Настройки → «Закладки», нажатие открывает нужный чат на нужном месте с подсветкой.
- **Резервная копия** (Настройки → Резервная копия): чаты, память, шаблоны, настройки, теги, закладки и список провайдеров одним файлом JSON. **API-ключи по умолчанию в файл не попадают.** Если включить переключатель **«Сохранить API-ключи»**, они кладутся в файл только **зашифрованными вашим паролем** (AES-256-GCM, ключ из пароля через PBKDF2, 250 000 кругов). Пароль нигде не хранится и восстановить его нельзя. При восстановлении приложение спрашивает пароль и возвращает ключи в защищённое хранилище, уже имеющиеся на телефоне ключи не перезаписываются.
- **Копирование и «Поделиться»** под каждым ответом; у вашего сообщения долгое нажатие даёт «Копирование» и «Выделение текста».

### ☁️ Аккаунт и облачная синхронизация (по желанию)

- Вход **по коду на почту** (регистрация и вход одним потоком, без пароля) и по паролю, через Supabase Auth.
- Кнопка «Аккаунты на этом телефоне»: быстрый вход в аккаунты, в которые уже входили.
- **Чаты и память синхронизируются** между устройствами (таблица `sync_items`, у каждого пользователя свои данные, SQL в `features/sync/schema.sql`).
- Можно пользоваться **без аккаунта**: тогда всё остаётся на телефоне. Адрес сервера задаётся в приложении.
- При выходе чаты и память с телефона очищаются (в облаке остаются), перед этим несохранённое отправляется в облако.

### 💸 Расходы и токены

Под каждым ответом: сколько токенов ушло и примерная цена (у OpenRouter берётся реальная). Экран **«Расходы и токены»**: сводка, цены можно править,
**месячный лимит** с предупреждением на 80% и 100%.

### 🎨 Внешний вид и ощущения

- Тема **Авто / Светлая / Тёмная**, спокойный дизайн без пёстрых плиток, плавная анимация клавиатуры и ничего не прыгает.

## 🤖 Агент-программист

Включается кнопкой с терминалом в поле ввода (или командой `/agent`). Вместо одного ответа модель получает **настоящие инструменты** (tool calling,
как у Codex и Claude Code) и сама ведёт работу циклом: **изучить код → внести правку → запустить проверку → прочитать ошибку → исправить → повторить**,
пока всё не заработает или она не упрётся в блокер.

**Инструменты модели**

| Инструмент | Что делает |
|---|---|
| `list_dir` | Список файлов и папок |
| `read_file` | Чтение с номерами строк, большие файлы диапазонами |
| `search` | Поиск по проекту (grep, регулярные выражения, маска файлов) |
| `edit_file` | Замена точного фрагмента (должен встречаться ровно один раз, иначе понятная ошибка) |
| `apply_patch` | Несколько правок за один вызов в одном или нескольких файлах; «всё или ничего»: если одна не подошла, файлы не меняются |
| `write_file` | Создание и перезапись файла (побайтно точно, в том числе юникод и большие файлы) |
| `run_command` | Команда оболочки в папке проекта с таймаутом, вывод и код выхода возвращаются модели |
| `update_plan` | Список задач с отметками, который виден вам по ходу работы |
| `web_fetch` | Чтение веб-страницы или документации как текста (ссылки сохраняются), постранично; новый сайт подтверждаете вы |
| `task` | **Подагент**: отдельный контекст, только чтение (`list_dir`, `read_file`, `search`, `web_fetch`), возвращает краткий отчёт; несколько `task` в одном ответе идут параллельно |
| `skill` | Загрузить инструкцию навыка по имени (см. «Навыки» ниже) |
| `read_image` | Посмотреть картинку из папки проекта (png, jpg, webp, gif до 400 КБ, например скриншот), если у модели есть зрение |
| `mcp__сервер__инструмент` | Инструменты подключённых MCP-серверов (см. ниже) |

**Инструкции проекта.** Если в корне папки проекта лежит `KAIREMA.md`, `AGENTS.md` или `CLAUDE.md` (берётся первый найденный, до 12 000 знаков), агент читает его перед работой: правила, команды сборки и тестов, стиль. В чате появляется карточка «Инструкции проекта». Включается и выключается в настройках агента. Файл из чужого репозитория может содержать вредные указания, поэтому подтверждения остаются в силе.

**MCP-серверы.** Настройки агента → «MCP-серверы…»: добавьте HTTP-адрес сервера (Streamable HTTP) и, если нужно, токен (хранится в защищённом хранилище Android, в копию не попадает). Инструменты сервера становятся доступны агенту. Вызов спрашивает вас (по серверу, можно «до конца чата»); в режиме «Только чтение» разрешены только инструменты с пометкой readOnlyHint. Серверы, запускаемые командой (stdio), не поддерживаются.

**Навыки.** Готовые сценарии, которые вызываются командой в начале сообщения: `/init` (создать или обновить `AGENTS.md`), `/review` (проверить последние изменения, ничего не правя), `/tests` (запустить тесты и исправить падения), `/continue` (продолжить прерванную работу). Свой навык: файл `.kairema/skills/имя.md` в папке проекта (описание можно задать строкой `description:` в начале файла); одноимённый файл заменяет встроенный. После имени можно дописать уточнение: `/review проверь модуль api`. Модель видит список навыков и может сама загрузить нужный инструментом `skill`.

**Хуки проекта.** Файл `.kairema/hooks.json` описывает команды, которые приложение запускает само: `after_edit` (после правки файла по шаблону, например `*.py`, вывод попадает в ответ инструмента), `before_command` (команда с `block` или проверкой, код выхода не 0 запрещает), `on_finish` (когда модель закончила; при ошибке она получает вывод и исправляет, до 2 раз). Пример: `{"hooks":[{"event":"after_edit","match":"*.py","run":"python -m pyflakes {file}"},{"event":"on_finish","run":"python -m pytest -q"}]}`. **По умолчанию хуки выключены**: они запускают команды без вопросов, поэтому включаются отдельной настройкой агента «Хуки проекта», только для своих проектов. Если хуки найдены, но выключены, в чате появляется карточка с подсказкой.

**Продолжение работы.** Журнал действий последних двух запусков агента (что сделано, что упало, план) попадает в историю разговора, в том числе у прерванного запуска без итогового ответа. После остановки или перезапуска приложения достаточно написать «продолжай» или `/continue`.

**Картинки.** Картинку, приложенную к сообщению в чате, агент получает как обычно (нужна модель со зрением). Картинки из папки проекта читаются инструментом `read_image` (до 400 КБ: файл передаётся через оболочку по кускам).

**Где выполняется**: в **Termux**, если он установлен и разрешён (есть git, python, node), иначе в **песочнице приложения** (без git и python). Режим «Авто» выбирает сам, можно зафиксировать вручную. Папку проекта можно выбрать обзором каталогов.

**Режимы подтверждений** (как у Codex и Claude Code)

| Режим | Поведение |
|---|---|
| Только чтение | Читает и ищет, ничего не меняет и не запускает |
| Спрашивать (по умолчанию) | Читает сам; каждую правку и команду показывает и ждёт «Разрешить» (можно «разрешать такое до конца чата») |
| Правки сами | Файлы правит сам, команды (кроме безопасных вроде `ls`, `git status`) спрашивает |
| Полный авто | Правит и запускает всё сам, но опасные команды (`rm -r`, `dd` и подобные) спрашивает всегда |

**Контроль и безопасность**
- Файловые инструменты **работают только внутри папки проекта** (пути с `..`, абсолютные и `~` отклоняются).
- **Git-контрольные точки**: перед запуском делается снимок проекта (не трогает ветки, индекс и историю), кнопки **«Изменения»** (цветной дифф) и **«Откатить к точке»** работают и после перезапуска приложения. Без git остаётся откат по снимкам файлов запуска.
- **Карточки шагов** в чате: что вызвано, с какими аргументами, что получилось, раскрываются по нажатию.
- **Защита от зацикливания**: повторяющийся вызов сначала получает предупреждение, потом запуск принудительно завершается итогом; настраиваемый **лимит шагов** (20 / 40 / 80 / 150).
- **Кнопка «Стоп»** прерывает запрос и текущую команду.
- **Уведомления**: «агент ждёт разрешения» и «агент закончил», когда приложение свёрнуто; служба переднего плана не даёт Android усыпить прогон. Предупреждение при батарее ниже 15%.
- Старые результаты инструментов сжимаются, чтобы длинный прогон не упёрся в окно контекста.
- В историю чата попадает итог агента, а не весь ход работы.

> ⚠️ Команды выполняются в оболочке телефона, и запереть их внутри папки проекта нельзя. Режим «Полный авто» включайте осознанно.
> Нужна модель с поддержкой вызова инструментов.

## 🔒 Приватность и безопасность

- **API-ключи** хранятся в Android Keystore (`data/SecureKeys.kt`) и не попадают в журнал и облако. В интерфейс и в резервную копию они выходят только по вашему явному выбору «Сохранить API-ключи»: тогда мост на мгновение отдаёт их странице, она сразу шифрует их вашим паролем, и в файл идёт только шифртекст.
- **Мост между интерфейсом и Kotlin защищён токеном** (`bridge/Guard.kt`): терминал, ключи, запросы к провайдерам и установка обновлений требуют его.
- **Запросы идут напрямую** от телефона к выбранному вами провайдеру. Посредников между вами и провайдером нет.
- **Чаты лежат на устройстве** (SQLite). Облачная синхронизация включается только если вы вошли в аккаунт.
- **Нет рекламы, аналитики и сторонних SDK**: из зависимостей только OkHttp.
- **Безопасный вывод**: Markdown строится через DOM без `innerHTML`, ссылки только `http(s)`.
- **Подтверждение действий**: команды из терминала и действия агента выполняются только с вашего разрешения (кроме режимов, где вы сами это разрешили), опасные требуют отдельного.
- **Подписанные релизы**: постоянный ключ подписи, обновление ставится поверх без потери данных. Ключ хранится в секретах GitHub и не лежит в репозитории.
- **Обновление проверяет адрес** загрузки: только `https`, только `github.com/<репозиторий>/releases/download/`, без логинов, портов и `..`.

### Как добавить, убрать или заменить функцию

Каждая функция живёт в папке `assets/ui/features/<имя>` (скрипты и стили), строки подключения перечислены в `index.html`.
- **Убрать необязательный модуль**: удалить папку и её строки в `index.html`.
- **Добавить модуль**: новая папка `features/<имя>`, свои строки в `index.html` перед `core/app.js`. Модуль подключается к ядру через `Hooks.on('app:ready' | 'chat:answer' | 'msg:render' | 'settings:rendered' | …)` и `i18nAdd({...})` для переводов, правки ядра минимальные.
- Модули `markdown`, `chats` и `providers` обязательные: ядро вызывает их напрямую.
- Новая нативная возможность идёт в свой пакет `java/com/kairema/app/<имя>/`.

### Сборка и выпуск

Сборка идёт в **GitHub Actions**, ничего локально ставить не нужно (всё можно делать с телефона).
1. Загрузите `kairema.zip` в корень репозитория.
2. Сборка сама распакует архив поверх `app/`, `docs/`, `README.md`, `settings.gradle.kts`, `.gitignore`, удалит zip и запустит Kotlin-тесты.
3. Соберётся debug APK (раздел Actions → Artifacts), подписанный release APK и **GitHub Release** `v<версия>` с файлом `Kairema-<версия>.apk`.

Настройка подписи и релизов: [`docs/RELEASE_SETUP.md`](docs/RELEASE_SETUP.md), готовый workflow: [`docs/build.yml.example`](docs/build.yml.example).
Обновление из приложения: [`docs/UPDATER_SETUP.md`](docs/UPDATER_SETUP.md). Облако и вход: [`docs/AUTH_SETUP.md`](docs/AUTH_SETUP.md).

**Версия** хранится в трёх местах: `app/build.gradle.kts` (`versionName` и `versionCode`), `core/config.js` (`APP_VERSION`) и строка «Текущая версия» внизу этого файла.

**Подпись debug-сборок.** `app/debug.keystore` лежит в репозитории намеренно и нужен только для debug-сборок (пароль `android`, alias `androiddebugkey`): благодаря ему новые debug-APK ставятся поверх старых. Ключ release-подписи в репозиторий не кладётся никогда.

- Сборка и подписанный release APK в GitHub Actions.

**Не проверено автоматически**
- Нативный Kotlin, зависящий от Android (`Bridge.kt` потоковый разбор и вызовы инструментов, `Updater.kt`, терминал, уведомления) компилируется только в CI и проверяется на телефоне владельцем.
- Агент не прогонялся на всех провайдерах: нужна модель с поддержкой вызова инструментов.
- Хуки, навыки и `read_image` проверены только в браузере с настоящей оболочкой, на телефоне ещё нет; `read_image` ограничен 400 КБ из-за размера вывода оболочки.
- Сетевой метод `Bridge.httpReq` (Kotlin) не компилировался локально; MCP проверен только на сымитированном сервере, не на настоящих. Сервер, который держит SSE-поток открытым после ответа, может зависнуть до таймаута в 60 секунд.
- Работа с git и python в Termux на разных телефонах, показ уведомлений и обновление из приложения зависят от версии Android и оболочки производителя.

**Известные ограничения**
- Команды агента и терминала нельзя запереть внутри папки проекта.
- Termux отдаёт вывод только после завершения команды.
- Теги и закладки хранятся на устройстве и не синхронизируются с облаком (но входят в резервную копию).
- Голосового ввода и озвучки нет: их убрали намеренно.
- Вход через Google пока не добавлен.
