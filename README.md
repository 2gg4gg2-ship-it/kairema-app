# Kairema

Android-приложение: ИИ-чат с вашим провайдером (BYOK), терминал и настройки.
Интерфейс написан на HTML/CSS/JS и работает внутри WebView, нативная часть на Kotlin.

## Структура

```
.github/workflows/build.yml   сборка debug APK и распаковка обновлений
settings.gradle.kts           настройки Gradle
app/
  build.gradle.kts            зависимости, версия, applicationId
  src/main/
    AndroidManifest.xml       разрешения и экран входа
    assets/ui/                интерфейс (WebView)
      index.html              точка входа: список подключённых модулей
      core/                   ядро: app.js (экраны), styles.css, hooks.js (события и переводы), config.js (версия, сервер)
      features/               модули, у каждого своя папка
        markdown/             разметка ответов ИИ (обязательный)
        chats/                история чатов (обязательный)
        providers/            провайдеры ИИ, выбор модели (обязательный)
        auth/                 аккаунт: вход по коду на почту и по паролю (необязательный)
        memory/               память: факты сохраняются на устройстве и попадают в запросы к ИИ (необязательный)
        sync/                 облачная синхронизация чатов и памяти через Supabase; SQL в schema.sql (необязательный)
        terminal/             терминал: настоящая оболочка Android, кнопка «Выполнить» под командами ИИ (необязательный)
    java/com/kairema/app/
      MainActivity.kt         окно, WebView, кнопка «Назад», выбор файлов
      bridge/Bridge.kt        мост JS <-> Kotlin (провайдеры, чат)
      terminal/Shell.kt       запуск команд в /system/bin/sh, вывод кусками
      terminal/TermuxRunner.kt   запуск команд в Termux через RUN_COMMAND, TermuxResultReceiver.kt принимает результат
      data/SecureKeys.kt      API-ключи в Android Keystore
```

## Как добавить, убрать или заменить функцию

Каждая функция живёт в папке `assets/ui/features/<имя>` (скрипты и стили). Её строки перечислены в `index.html`.
- **Убрать необязательный модуль** (например, auth): удалить папку и его строки в `index.html`.
- **Добавить модуль**: новая папка `features/<имя>`, свои строки в `index.html` перед `core/app.js`. Модуль подключается к ядру через `Hooks.on('app:ready' | 'settings:rendered', ...)`, добавляет экран в `SCREENS` и свои переводы через `i18nAdd({...})`. Править `core/app.js` не нужно.
- Модули markdown, chats и providers обязательные: ядро чата вызывает их напрямую.
- Нативный код: новая возможность идёт в свой пакет в `java/com/kairema/app/<имя>/`.

## Возможности

- Терминал: две оболочки на выбор. Android (встроенная) и Termux (полноценный Linux: python, git, node; нужны установка Termux, разрешение «Run commands in Termux environment» для Kairema и allow-external-apps=true в Termux). Режим агента: кнопка «Выполнить и продолжать сам» запускает до 8 шагов подряд с отправкой результатов ИИ; опасные команды только вручную. Настоящая оболочка Android (системные команды, без python и git). Блоки ```bash в ответах ИИ получают кнопку «Выполнить» с подтверждением; результат или ошибку можно отправить ИИ одной кнопкой. Кнопка «Диагностика» показывает, что доступно на телефоне.
- Облако: чаты и память после входа сохраняются в Supabase (таблица sync_items, свои данные у каждого пользователя), объединяются между телефонами, побеждает последнее изменение. Один раз нужно выполнить `features/sync/schema.sql` в SQL Editor.
- Аккаунт: вход по коду на почту и по паролю (Supabase). Сервер вводится в приложении (Настройки, Аккаунт). Google добавится отдельным шагом.

- Провайдеры ИИ: OpenAI-совместимые API и Anthropic, ключи в Keystore.
- Чат с потоковым ответом и разметкой Markdown. ИИ получает системную инструкцию: отвечать на языке вопроса и оформлять ответ.
- В чате можно переключать провайдера и модель (строка с названием вверху). В списке моделей сначала бесплатные, потом платные (если провайдер сообщает цены, например OpenRouter).
- Переключатель поиска в интернете запоминается между запусками.
- Провайдер ИИ: название, API URL и ключ. Сначала проверяется ключ, потом приложение показывает список моделей этого провайдера, затем проверяется выбранная модель. Адрес openrouter.ai дополняется до /api/v1 сам.
- Профиль пустой по умолчанию: имя спрашивается после онбординга и в настройках, хранится в localStorage, без имени показывается «Гость». «Память» пустая, терминал честно помечен как демо.
- История чатов: список, сохранение между запусками (localStorage), переименование, удаление. Текст файла в истории до 20 000 знаков, фото и PDF не сохраняются; при переполнении хранилища показывается сообщение, сохранённые чаты не теряются.
- Вложения: фото (галерея и камера), текстовые файлы и код, PDF (только Anthropic).
- Поиск в интернете: Tavily, Brave Search, Serper (результаты добавляются к вопросу).

## Подпись debug-сборок

`app/debug.keystore` лежит в репозитории намеренно и нужен ТОЛЬКО для debug-сборок (пароль `android`, alias `androiddebugkey`). Благодаря ему новые APK ставятся поверх старых без удаления. Для релиза нужен другой, секретный ключ.

## Правила

- API-ключи живут только в Keystore, в интерфейс не передаются.
- Один слой, одна папка: интерфейс в `assets/ui`, нативный код в `java`.
- Новые возможности добавляются новыми файлами в нужной папке, без смешивания.

## Как обновлять

Загрузите `kairema.zip` в корень репозитория. Сборка сама распакует его в папки
выше, удалит zip и соберёт APK (раздел Actions → Artifacts).

Текущая версия: 0.9.0
