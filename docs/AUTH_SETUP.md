# Вход по почте: что настроить в Supabase (один раз)

Приложение шлёт на почту **код** (регистрация и вход одним потоком). Без этих двух настроек код не придёт или придёт ссылкой.

## 1. Письма с кодом (шаблоны)
Supabase, проект kairema: Authentication, Emails, Templates. Откройте **Magic Link** и **Confirm signup**.
В тексте письма оставьте строку с `{{ .Token }}` (это 6 цифр). Пример: `Ваш код для входа в Kairema: {{ .Token }}`.
Ссылку `{{ .ConfirmationURL }}` можно убрать. Нажмите Save.

## 2. Своя отправка писем (SMTP)
Встроенная почта Supabase: 2 письма в час и только на адреса участников проекта. Для всех остальных нужен свой SMTP.
Бесплатный вариант: Brevo (300 писем в день, адрес отправителя подтверждается по почте, свой домен не нужен).
Supabase: Authentication, Emails, SMTP Settings, Enable custom SMTP. Вписать данные SMTP из Brevo (Host, Port 587, логин, пароль SMTP) и адрес отправителя.
Лимит писем в час потом можно поднять: Authentication, Rate Limits.

## 3. Адрес и публичный ключ в приложении
Сейчас адрес проекта и publishable key вводятся на экране «Аккаунт» (Сервер: изменить). Чтобы друзьям не вводить их вручную,
впишите их в `app/src/main/assets/ui/core/config.js` (`CONFIG.supabaseUrl`, `CONFIG.supabaseAnonKey`). Это публичные данные, не секрет
(секретный ключ `sb_secret_` вписывать нельзя).

## Безопасность
Вход только по адресу почты без кода небезопасен: любой, кто знает чужую почту, прочитал бы чужие чаты. Поэтому подтверждение кодом обязательно.
Быстрый вход «Аккаунты на этом телефоне» работает без кода, потому что телефон уже подтверждён при первом входе; «Убрать» отзывает вход.
