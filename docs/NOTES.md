## Сделано (кратко)
- Провайдеры ИИ (OpenAI-совместимые и Anthropic), проверка ключа, выбор модели (бесплатные сверху), переключение провайдера и модели в чате.
- Чат: потоковый ответ, Markdown, история чатов (закрепление, переименование, удаление), вложения (фото, текст, PDF для Anthropic), поиск в интернете.
- Память: факты на устройстве и в запросах к ИИ. Вход (код на почту и пароль, Supabase) и облачная синхронизация чатов и памяти.
- Терминал: оболочка Android и Termux (запуск через RUN_COMMAND, запрос разрешения окном, резерв startForegroundService), кнопка «Выполнить» под командами ИИ, режим агента (до 8 шагов).
- «Поделиться», копирование, файлы из ответов ИИ (HTML, CSV, таблицы, PDF) и экран «О приложении» (сделал другой Claude).

## Открытые задачи (по приоритету, решает владелец)
1. Проверить у владельца кнопку «Проверить Termux» (таймаут увеличен до 60 с в 0.12.2) и сценарий агента в чате.
2. Входящий «Поделиться» (отправить текст или файл из другого приложения в Kairema): Intent-фильтр ACTION_SEND, передача в чат. Исходящее уже есть в `share/`.
3. Голос: системное распознавание речи и озвучка ответа (Kotlin: SpeechRecognizer, TextToSpeech), затем режим «поговорить с ИИ».
4. Выбор разных моделей под задачи (быстрая для заголовков и сжатия, мощная для ответов). Только JS.
5. Поиск по файлам и коду на устройстве (по ключевым словам, без внешних сервисов), выбор файлов и папок.
6. Вход через Google в системном окне выбора аккаунта (Credential Manager, нужны AndroidX и ключи в Google Cloud, отпечаток SHA-1 из `app/debug.keystore`).
7. Код на почту вместо ссылки: нужна своя отправка писем (SMTP).
8. Ссылки: JS-плагины и пользовательские скрипты: только с «песочницей», пока не делаем.
Решение владельца: друзей, карту и мессенджер не делаем.

## Известные ограничения
- Termux возвращает результат только после завершения команды (не по ходу); интерактивные программы (nano, vim, пароли) не работают; команда ограничена по времени.
- Встроенная оболочка Android: нет curl, wget, python, git; файлы из папки приложения не запускаются.
- Supabase бесплатный: встроенная почта 2 письма в час; проект засыпает после недели без активности.
