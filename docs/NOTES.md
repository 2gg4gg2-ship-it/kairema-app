## Сделано в 0.17.0 (Claude-Ядро: поиск и исправление веб-поиска)
- Новый модуль `features/search` (search.js, search.css) и Kotlin `search/SearchIndex.kt`, `search/SearchBridge.kt` (JS-имя `KairemaSearch`, отдельный файл `kairema_search.db`, чаты в `kairema.db` не затронуты). Индекс: заголовки (t), сообщения (m), блоки кода с языком (c). FTS5, если нет в прошивке, то запасной режим LIKE; без Kotlin ищет JS по `Chx.list`. Индекс обновляется через `sync:touch`/`sync:delete`, сверяется при запуске и при открытии поиска. Поиск открывается кнопкой с лупой в списке чатов.
- Общие файлы, точечные правки: `core/app.js` (`respond`: новый текст правил к результатам поиска; пустой ответ при поиске повторяется один раз без результатов, `mkHist`/`run`), `features/providers/providers.js` (`sysPrompt`: описание приложения, запрет выдумывать создателя/отзывы, результаты поиска могут быть не по теме), `features/chats/chats.js` (кнопка поиска `data-chs` в списке чатов, только если есть `Srch`), `index.html` (строки search), `MainActivity.kt` (`KairemaSearch`).
- Причины бага «с поиском не отвечает / выдумывает»: (1) весь вопрос уходил поисковику как запрос, для вопросов про приложение или про самого ИИ выдача мусорная; (2) системная инструкция требовала «опираться на результаты», и модель пересказывала мусор (про «Kairema» как компанию, ROE и т. п.); (3) если модель возвращала пустой ответ (например, только размышления), показывалась ошибка, а в экспорте чата такие сообщения пропадали; (4) выдуманные ответы остаются в истории и модель продолжала их и при выключенном поиске, плюс в инструкции ничего не говорилось, что это за приложение, поэтому появились «Kairema Labs». Старые испорченные ответы лучше удалить или начать новый чат.
- Не проверено на телефоне: весь новый Kotlin (сборку проверяет CI), наличие FTS5 на iQOO (режим виден внизу экрана поиска: «SQLite FTS5» или «на устройстве»). JS проверен в Playwright с имитацией `KairemaSearch`; `docs/tests/search.test.js` написан по образцу остальных тестов, но здесь не запускался (нет jsdom).
- Идеи дальше: учитывать роль сообщения (вы/ИИ) в результатах, поиск по тексту вложенных файлов, подсветка найденного слова в открытом чате, умный запрос для веб-поиска (перефразирование вопроса моделью).

## Известные ограничения
- Termux возвращает результат только после завершения команды (не по ходу); интерактивные программы (nano, vim, пароли) не работают; команда ограничена по времени.
- Встроенная оболочка Android: нет curl, wget, python, git; файлы из папки приложения не запускаются.
- Supabase бесплатный: встроенная почта 2 письма в час; проект засыпает после недели без активности.
