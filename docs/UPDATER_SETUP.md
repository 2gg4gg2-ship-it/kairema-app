# Обновление из приложения: что сделать один раз

Приложение (Настройки → «Обновление») берёт новую версию из раздела **Releases** репозитория `2gg4gg2-ship-it/kairema-app`.
Сейчас сборка кладёт APK только в «артефакты» запуска (их нельзя скачать без входа в GitHub), поэтому нужен один дополнительный шаг в `.github/workflows/build.yml`.
Файл `.github/` в архив обновления не входит, правится руками (с телефона: репозиторий → `.github/workflows/build.yml` → значок карандаша).

## Что добавить

В самый конец `build.yml`, после шага `actions/upload-artifact@v4`, добавить (отступы как у соседних шагов, два пробела перед `-`, шесть у `name`):

```yaml
      - name: Publish release with APK
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          VER=$(grep -m1 'versionName' app/build.gradle.kts | sed -E 's/.*"([^"]+)".*/\1/')
          cp "$(ls app/build/outputs/apk/debug/*.apk | head -1)" "Kairema-$VER.apk"
          NOTES=$(grep -m1 -F -- "- $VER:" docs/CHANGELOG.md | cut -c1-1400)
          gh release delete "v$VER" --yes --cleanup-tag 2>/dev/null || true
          gh release create "v$VER" "Kairema-$VER.apk" --title "Kairema $VER" --notes "${NOTES:-Kairema $VER}" --target "$(git rev-parse HEAD)"
```

Права на запись (`permissions: contents: write`) в файле уже стоят.

## Как это работает дальше
1. Заливаешь `kairema.zip`, сборка распаковывает исходники, собирает APK и создаёт релиз `v<версия>` с файлом `Kairema-<версия>.apk`.
2. В приложении: Настройки → «Обновление» → «Скачать и установить». Если версия в релизе новее установленной, кнопка появится. Раз в сутки приложение проверяет само (выключается в этом же окне).
3. Первый раз Android попросит разрешить установку из Kairema (откроются настройки, включи переключатель, вернись и нажми кнопку ещё раз).

## Почему обновление встанет поверх
Подпись берётся из `app/debug.keystore`, он лежит в репозитории, поэтому у всех сборок один ключ и Android принимает новую версию поверх старой без удаления. Если этот файл заменить, обновление поверх перестанет ставиться (придётся удалить приложение, данные при этом пропадут, сначала сделайте резервную копию).

## Что не проверено
Kotlin (`update/Updater.kt`, `Bridge.updCheck/updInstall`) не компилировался, шаг для `build.yml` не запускался. Если сборка упадёт на новом шаге, ошибка будет видна во вкладке Actions; приложение при этом продолжит собираться, если убрать шаг.
