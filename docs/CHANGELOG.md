# История версий

Одна строка на версию. Новые записи добавляй сверху.

- 0.15.0: поле ввода с меню «+», Thinking/Instant, создание изображений, глубокое исследование, индикатор голоса, зелёный/красный поиск, больше места под статус-бар, окно «Новый чат» по центру.
- 0.14.0: заставка с видео-анимацией логотипа и логотип Kairema везде, приложение на весь экран (отступ под статус-бар), тема по системе телефона, таблицы в ответах листаются вбок, пересылка: 10 сообщений, страница чата только для чтения, 4 действия.

- 0.12.1: Termux: если Android не даёт запустить службу из фона, запуск как foreground-службы.
- 0.12.0: Termux: системное окно запроса разрешения «Run commands in Termux environment».
